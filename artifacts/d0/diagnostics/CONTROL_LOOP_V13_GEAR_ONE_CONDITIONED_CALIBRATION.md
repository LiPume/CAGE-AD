## 为什么 V8 不能直接拿来调油门

V8 的不同油门都从静止开始，CARLA 自动变速箱进入 1 挡分别等待约 1.0 到 3.15 秒。终点速度差同时包含油门作用和不同挂挡等待，不能据此拟合 bridge 增益或 Apollo 标定表。

V12 又确认，Apollo 有正加速计划，bridge 也准确执行了 1.5 倍换算；问题已经集中到当前纵向标定链。现在需要在相同初始挡位和速度下测量 CARLA Lincoln 的真实响应。

## 冻结测量方法

不启动 Apollo 和 bridge。Town01、同一平直位置、同一 `vehicle.lincoln.mkz_2017`、零其他车辆、20 Hz 固定步长、自动变速箱和车辆物理保持原样。

每个测量样本都创建新车，并先统一执行：

1. 用 `0.40` 油门预热；
2. 等待 CARLA 真实挡位为 1 且速度首次达到 `1.0 m/s`；
3. 确认起始速度不超过 `1.15 m/s`；
4. 立即切换到待测油门，前 0.5 秒作为过渡，后 2.5 秒作为评价窗口。

待测 CARLA 油门固定为：

`0.20, 0.2355, 0.2575, 0.30, 0.35, 0.40, 0.50`

每档独立重复 3 次，共 21 个样本。`0.2355` 是当前 Apollo 最低油门经 1.5 倍换算后的实际值，`0.2575` 接近 V11 中位数；更高档只用于覆盖期望加速度，不代表预先决定采用。

## 冻结通过条件

- 21 个样本都在 8 秒内完成统一预热；
- 每个测量都从真实 1 挡、`1.0–1.15 m/s` 开始，保持自动挡，无刹车、倒车或手刹；
- 每个样本完整 60 帧，控制回读与目标误差小于 `1e-6`；
- 同一油门 3 次评价窗口的中位加速度极差不超过 `0.20 m/s²`；
- 随油门增加，各档中位加速度不得下降超过 `0.05 m/s²`；
- 测量范围必须同时覆盖接近零的响应和至少 `0.35 m/s²` 的正加速度，才能进入表设计。

任一条件失败都保留原始记录，不拟合标定表、不改 bridge 增益。最多允许一次明确的测量基础设施修复。本轮是控制诊断证据，不是 D0 数据集，不运行正式 TTC。

预算：10 分钟开机时间、256 MiB 新增文件。

## 测量结果

唯一一次运行 `CARLA_V13_GEAR_ONE_01` 完成全部 21 个样本：

- 每个样本都用 29 帧完成统一预热；
- 每次测量起点都是真实 1 挡、`1.0176 m/s`；
- 所有样本均为 60 帧，油门回读正确，未刹车、倒车、拉手刹或开启手动挡；
- 同一油门的 3 次结果逐项相同，重复极差全部为 0；
- 测量范围覆盖负加速度到大于 `0.35 m/s²` 的正加速度。

但是预注册的“评价窗口瞬时加速度中位数随油门单调”失败：

- `0.20 → -0.0705 m/s²`
- `0.2355 → +0.0355 m/s²`
- `0.2575 → -0.0422 m/s²`
- `0.30 → +0.0291 m/s²`
- `0.35 → +0.0757 m/s²`
- `0.40 → +0.1787 m/s²`
- `0.50 → +1.1985 m/s²`

`0.2355` 到 `0.2575` 的中位数下降约 `0.0778 m/s²`，超过预注册允许的 `0.05`，所以总结果必须为 `FAIL`。

审计原始速度后发现，低速瞬时加速度在正负之间周期振荡，中位数会受测量窗口落在振荡的哪个相位影响。用同一冻结窗口的速度首尾变化计算平均加速度，仅作为修复依据而不作为 V13 结果，可得到：

- `0.20 → -0.1404 m/s²`
- `0.2355 → -0.0862 m/s²`
- `0.2575 → -0.0833 m/s²`
- `0.30 → +0.0260 m/s²`
- `0.35 → +0.0717 m/s²`
- `0.40 → +0.2708 m/s²`
- `0.50 → +1.1423 m/s²`

这组速度变化严格单调，并与每档 3 次完全重复相符，说明失败来自主指标选错，不是控制回读、挡位或仿真随机失效。

**不可以。** V13 按预注册规则判失败，禁止直接拟合标定表或修改 bridge 增益。
