# CARLA Lincoln 纵向开环响应 v8 计划与结果

状态：**测量完成但控制回读门槛失败；不得据此建立油门映射**

分支：`codex/apollo-d0-control-loop-repair-v8`

基线提交：`cfd69d208cf03d2f7bc9444f93f0e0f6ffb9f325`

## 为什么需要这次测量

V7 已修好启动、转向和有界加速度反馈，但最终实际/计划速度比只有 `0.5584`。当前 Apollo 最常见的最低油门 `15.7%` 经旧 bridge 的 `1.5` 倍后，CARLA 实际收到约 `0.2355`。

不能直接把倍数调大，因为还不知道同一辆 Lincoln 在不同 CARLA 油门下的真实速度和加速度曲线。V2 的 `1.910828` 是一次单点反推，已经证明不能作为因果结论复用。

## 冻结测量

不启动 Apollo 和 bridge。使用同一 Town01 平直位置、同一 `vehicle.lincoln.mkz_2017`、20 Hz 固定步长，每档从静止开始持续 8 秒：

`0.15, 0.20, 0.2355, 0.30, 0.40`

记录每帧速度、纵向加速度、位置、挡位和控制回读。每档重新创建车辆；零其他车辆；不施加故障或刹车；结果标记 `CONTROL_LOOP_DIAGNOSTIC_NOT_DATASET`。

一次运行完成全部五档，不增加档位、不延长时间。若任一档没有完整 160 帧、控制回读不一致、车辆不在前进挡或结果不随油门单调变化，本轮只报告测量失败，不建立映射。

即使测量成功，也只允许据此设计下一份车辆专用映射合同，不能在本轮直接修改 bridge 油门。

V8 预算 10 分钟、256 MiB。

## 测试后结果

五档都取得完整 160 帧，油门回读误差均小于 `1.2e-8`，刹车始终为 0，从未进入倒挡，8 秒终点速度也随油门严格增加：

- `0.15 → 0.290 m/s`
- `0.20 → 0.590 m/s`
- `0.2355 → 0.734 m/s`
- `0.30 → 1.199 m/s`
- `0.40 → 2.562 m/s`

但冻结的挡位一致性门槛失败。CARLA 自动变速箱从静止起步时先回报 0 挡，再进入 1 挡；五档的 0 挡帧数分别为 `63、42、34、26、20`，相当于约 `3.15、2.10、1.70、1.30、1.00 s`。油门越小，挂入前进挡越晚。

因此各档速度曲线同时混入了不同长度的挂挡等待，不能把终点速度差全部解释为油门响应。按预注册规则，本轮测量判失败，所有原始数据保留但不得用来拟合或选择 bridge 油门映射。

这个失败本身新增了一条重要根因：CARLA Lincoln 的低速纵向响应包含自动变速箱状态，不能只做“油门百分比→速度”的无状态比例。下一份合同必须先明确闭环里 Apollo 挡位、bridge 命令和 CARLA 实际挡位三者的时间关系，再决定是否需要车辆专用标定；不能直接调大油门。
