# V19 Lincoln 低速微小刹车检查

状态：**已完成；没有找到可分辨的渐进刹车区间；不生成数据集**

## 为什么做

V18 已证明 TTC 能产生，但 Apollo 在前车场景里出现“猛刹到几乎静止—再起步”。V3 只测过 CARLA 刹车
`0.03～0.15`，这些值都在低速下约 0.10 秒停车；还不知道 `0.001～0.02` 之间是否存在可重复的渐进区间。

本次不启动 Apollo 和 bridge，不改车辆物理，只测原始 Lincoln。每次让车进入真实前进挡并达到
`2.00～2.15 m/s`，然后施加 `0、0.001、0.003、0.005、0.01、0.02、0.03` 七档 CARLA 刹车；每档固定
重复 3 次，最长观察 3 秒。`0` 是滑行对照，其余覆盖 bridge 可能使用的微小刹车区。

## 运行前固定的判断

有效性要求：21 个样本完整；每次起始速度和前进挡满足条件；脚本请求与 CARLA 回读完全一致；运行前后车辆
物理不变。

若至少两个正刹车档的中位有效停车时间在 0.25～3.05 秒之间、随刹车增大总体不增加，且相邻档至少相差
0.10 秒，则记为 `PASS_RESOLVABLE_GRADUAL_REGION`，表示值得继续做负加速度标定。否则记为
`NO_RESOLVABLE_GRADUAL_REGION`，停止用标定表硬补偿，不改物理来追求正结果。

本次只允许一个正式运行，预算上限 300 秒开机时间、64 MiB 新增文件。测试结果将在运行后追加，任何结果都保留。

## 测试结果

唯一正式运行 `CARLA_V19_MICRO_BRAKE_01` 正常完成，执行源码提交为
`090f573797fb174ae005ea2a412489c3b354432e`，CARLA 开机 39.9236 秒。21 个样本全部达到起始速度、全部从
真实前进挡开始，CARLA 回读与请求完全一致，运行前后车辆物理未变。三次重复逐项得到相同结果。

| CARLA 刹车 | 中位停车时间 | 中位现象 |
|---:|---:|---|
| 0 | 3 秒内未停 | 3 秒后仍约 0.171 m/s |
| 0.001（0.1%） | 0.45 秒 | 停车距离约 0.7082 米 |
| 0.003（0.3%） | 0.45 秒 | 停车距离约 0.7078 米 |
| 0.005（0.5%） | 0.45 秒 | 停车距离约 0.7067 米 |
| 0.01（1%） | 0.45 秒 | 停车距离约 0.7052 米 |
| 0.02（2%） | 0.45 秒 | 停车距离约 0.6887 米 |
| 0.03（3%） | 0.40 秒 | 停车距离约 0.6710 米 |

所有正刹车档都能停车，但 0.1%～2% 的停车时间完全一样，3% 也只差一个 0.05 秒仿真步。按运行前固定的
“相邻档至少相差 0.10 秒”条件，本轮结论是 `NO_RESOLVABLE_GRADUAL_REGION`。

最通俗地说：这不是 Apollo 命令太大，也不是 bridge 把数值写错。CARLA 确实收到 0.001、0.003、0.005 等
不同值，但这辆 Lincoln 在约 2 m/s 下几乎只表现为“不刹”和“刹”两档。继续把 Apollo 负加速度表从 30%
改成 3%、0.3% 或 0.1%，仍得不到能够平滑控制的刹车。

因此 V18 的反复瞬停不能再靠猜标定表修复。正式场景和数据集继续暂停，当前工程终态应进入
`D0_MODIFY_INFRA`：TTC、场景和正向行驶已恢复，但 CARLA Lincoln 的低速制动 plant/physics 与 Apollo
需要的连续控制接口不匹配。若以后继续，必须另开一个明确版本，预登记并独立验证车辆物理层修复；不能在
protocol v1 内静默改物理、换车型或调场景来得到通过。
